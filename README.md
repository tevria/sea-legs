# Sea Legs

Seasickness relief on your phone. Breathe with a light that sits on a gyro-locked horizon, with an ocean-swell sound cue, a ship-motion clinometer and quick fixes for on deck.

Live: https://tevria.github.io/sea-legs/

Open it in Safari or Chrome, tap **Start breathing**, and allow motion access when asked. On iPhone, Share → Add to Home Screen opens it full screen like an app.
